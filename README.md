# A Due Passi Da – Sito Web Vetrina

Sito web statico per il B&B "A Due Passi Da" a Corato (BA).

## Sviluppo

Il sito è sviluppato seguendo il piano di implementazione in `docs/implementation_plan.md`.

## Tecnologie

- HTML5, CSS3, JavaScript (vanilla)
- Hosting: GitHub Pages
- Form: Formspree
- Mappa: Leaflet.js + OpenStreetMap
